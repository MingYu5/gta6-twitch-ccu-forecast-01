A launch-day Twitch viewer forecaster: given a game's release-day hour-1 viewer count, it forecasts hours 2-24 as five quantiles each, using a similarity-weighted pool of past comparable launches' release-day curves (kernel on the hour-1 scale and the pre-release ramp, with a bonus for a matching unlock pattern), fitted and calibrated by leave-one-out cross-validation over those comparables.

## Run it

```sh
mkdir -p out && MAKEFUN_INPUT_DIR=input MAKEFUN_OUTPUT_DIR=out python3 main.py
```
